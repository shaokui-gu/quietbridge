# 共享预览窗口

设计稿：[QuietBridge / 共享预览 · 右上锚定](https://www.figma.com/design/Tr6hAfLgUAulbXkagRyX3S?node-id=113-1074)。

## 交互

- 默认吸附宿主窗口右上角，16pt 内边距；宿主宽度变化时始终重新计算右边缘。
- 独立 30Hz 跟随循环只查询已绑定宿主窗口，不改变捕获目标或重建视频流。
- 跟随回调直接在主线程执行，同时注册 common 与 eventTracking 模式，拖动期间继续更新。
- 左下角 22×22pt 为唯一缩放热区；等比缩放，右上顶点不动。
- 画面其他区域可临时拖动避让，超过 3pt 才判定拖动；关闭按钮单独响应点击。
- 拖动不抢焦点，位置限制在宿主所在显示器可见范围；松开后保留 30 秒，再自动吸附回右上角。
- 重复拖动从最后一次松开重新计时；拖动过程中不超时归位。临时缩放保留原倒计时及当前右上顶点。
- 宿主移动、缩放或窗口身份改变会立即取消临时位置，30Hz 跟随循环在下一次回调恢复吸附；本轮尚未完成的拖动不覆盖新锚点。
- 结束共享、换捕获目标时清除临时位置和拖动状态。
- 预览同时受宿主内边界和显示器可见区域限制；窄窗或竖向源画面允许自动缩小至通常最小宽度以下。
- 结束共享时关闭跟随循环；沿用宿主身份、Space 回读及隐藏规则，不激活应用或切换用户 Space。

## 外观

- 全框视频，移除原 24pt 标题栏及顶部状态文字，保持源画面比例。
- macOS 26：原生 NSGlassEffectView；macOS 14/15：NSVisualEffectView 毛玻璃。
- 玻璃仅用于容器背景和悬浮关闭控件，源视频保持清晰；等待首帧或画面留白时可见玻璃底层。
- 12pt 连续圆角，无额外描边；由透明面板按圆角轮廓生成柔和阴影。
- 玻璃是视频下方的独立背景；最外层统一裁切玻璃、画面和控件，视频层自身也做圆角裁切。
- 窗口流关闭 ScreenCaptureKit 额外窗口框架/阴影，保留源窗口透明圆角；应用及桌面共享保持原始画面。
- 悬浮时显示右上角关闭按钮和左下角缩放提示。关闭按钮保留无障碍标签。
- 流状态仍通过工具诊断返回，不占用视频顶部。

## 验证

定向 Swift 回归覆盖：从窄窗连续扩到全屏宽度、多显示器坐标、宿主缩小、竖向源画面、
唯一缩放热区、固定右上顶点、30 秒临时位置及重复拖动续期、宿主几何变化立即取消、显示器
边界约束、eventTracking 模式持续回调与停止清理、视频满框、玻璃原生类型、悬浮按钮显示及命中。
测试不驱动用户应用或请求权限。

真实 Workbuddy 拖动/缩放的视觉流畅度、实际共享视频上的玻璃和投影效果仍须安装后验收。
0.6.1 build 84 已包含跟随、缩放及玻璃背景；其后修正了多余描边和外层方角。
Figma 已同步本轮无额外描边和临时拖动规则。
