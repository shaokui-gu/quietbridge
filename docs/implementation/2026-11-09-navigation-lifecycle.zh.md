## 已实现

### 原标签导航同步

- navigate 受理后，在确认回执之前发布“等待新文档”边界，清除旧 documentId；不把旧文档当作目的页。
- 同一任务、同一绑定持续核对 Chrome 当前顶层 frame 与原标签所在窗口。遇到漏报的跨文档导航、同文档 URL 变化或文档恢复时，补齐 epoch 并注入当前观察脚本。
- 标签移到其他窗口、进入受限页面或权限撤销时暂停，不激活窗口、不按焦点选择其他标签。
- 已入队命令仍固定原 documentId/epoch，不能迁移到替换文档。旧命令明确失败，后续观察可复用原绑定，无需每页 candidates+assign。
- 导航边界内的观察申请最多等待 3 秒再入队；轻量观察还要求 DOM 就绪。等待期间检查取消、任务身份、绑定和应用会话，并在锁内再次核验绑定。超时未入队时明确报告 BACKGROUND_WAITING。
- 页面 snapshot/read/diagnostics 等文档脚本增加最多 3 秒、且不超过命令有效期的回执等待。迟到结果不写入后续命令结果，不自动重放。

### 保留命令终态

- sync、result 和后续命令处理统一检查过期；没有新扩展心跳时也能查询已有命令是否过期。
- 最近最多 64 条过期／取消终态单独保留，不会因下一条命令覆盖而立即变为 unknown；正常结果仍最多保留 8 条，已消费 ID 有界保留。
- 已投递的过期／取消动作如实标记 mayHaveExecuted。迟到回执只确认消费，不恢复为成功，不重放输入。
- 结果未知的输入，包括未知结果的 navigate，仍要求 snapshot 复核。

### 导航支持轻量复核

- 仅对已成功受理、performed=true 的 navigate，允许当前绑定的新 epoch、新文档就绪且脱敏目的地址匹配后的 screenshot/read/diagnostics 解除导航复核等待。
- 重定向到不同路径、文档未就绪、旧 epoch 或旧文档的轻量观察不能解除等待。需要查看实际页面并确认。
- 点击、填写、选择、按键等输入仍要求 snapshot；轻量观察不产生新输入 ref，也不能使旧快照引用重新有效。
- navigation_observation 返回值及工具说明明确这一流程。STALE_DOCUMENT/STALE_TARGET 指引优先核实原绑定与当前文档，不要求每次重新分配。

### 坏回执不阻断后续心跳

- 只有属于已请求命令的回执才进入局部校验；格式或身份不合法时记录 INVALID_BROWSER_RESULT，不采信内容，返回拒绝确认并消费该命令。
- 未请求的 requestId、握手字段错误和归属不符仍拒绝整个请求，没有放宽 schema 或任务隔离。
- 本地请求被拒绝显示 request_rejected；传输不可用保留 host_unavailable；应用退出仍单独显示 application_stopped 并释放观察。
- native stderr 仅记录固定错误类别、异常类型、允许的 action 与合法 commandId，不输出任意异常文本、页面正文、完整 URL 或配置。
- Agent 对协议拒绝、存储不可用、无效结果得到通知用户的恢复指引；观察超时最多只读复查两次，禁止换输入通道或重复未知输入。

## 阅读路径

交互快照继续保留 300 元素上限，用于定位输入 ref；没有把整页正文塞进交互树。

1. 列表页用 read mode=links 获取已渲染链接。
2. 导航到有明确地址证据的话题后，用 read mode=content 分页读取已加载正文，按同一 readId/nextOffset 续读；maxChars 可取 4000–16000。
3. 需要视觉核实当前视口时截图；需要点击或填写时才获取交互 snapshot。

截图仅证明当前视口，不能凭一张图片宣称读取整个长话题或全部评论。read 也只涵盖当前 DOM；未加载的楼层、隐藏正文和登录限制没有被绕过。正文分片及通用文本块不能直接按评论条数计数。
