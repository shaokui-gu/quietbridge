# 虚拟鼠标跟随目标窗口层级

日期：2026-11-13。状态：已与同日的[预览宿主层级修正](2026-11-13-preview-host-ordering.zh.md)一起打包为 **0.6.28（111）**，扩展保持 **0.4.14**；实际包内容、三组件签名与隔离检查通过，尚未安装。

原 `AgentCursor` 使用屏保窗口层级及浮动面板，即使目标位于另一应用后方，光标仍可能出现在遮挡应用上方。本轮移除这一高层级，使用与原目标普通窗口相同的 `.normal` 层，并持续把自有光标排到实际操作窗口紧邻上方。预览框的锚点仍是宿主窗口，光标的锚点是输入目标；两者不能混用。

预览卡片与光标复用 `WindowOverlayOrdering`，按窗口 ID、PID、普通窗口层与真实屏幕顺序验证，只对自己的浮层发出排序调用，不激活、置前或移动目标应用。另一应用置前后覆盖目标及光标；目标被隐藏、离开当前 Space 或顺序尚未确认时，真实光标的画面隐藏。原有 Space 集合回读、迁移限制及失败清理规则继续生效，不切换用户桌面、不加入所有 Space。

光标每帧读取原窗口的身份与边界，窗口消失或同一窗口号归属改变就隐藏；目标移动、缩放后按新边界裁切箭头、光晕和涟漪。指针坐标落在目标外时隐藏，不将其钳到窗口边缘冒充正确位置。画面显隐禁用隐式动画，避免隐藏时留下淡出残影。60Hz 时钟同时注册 common 与 eventTracking 模式，用户拖动窗口时继续更新；30 秒空闲截止时间仍由原动画状态控制，渲染或层级检查不续期。

共享镜像仍属于原目标的捕获内容，使用同一 `CursorState` 的坐标与动画，不把镜像当作真实桌面浮层已经显示的证据。未确认的 Space 或无效目标仍清除真实浮层和镜像。

验证：

- 合并预览与光标后的 68 项 Swift 回归通过，包含原 Space 路由、时间/镜像状态、目标与宿主身份分离、遮挡排序、PID 变化、多显示器边界裁切及真实绘制裁切。绘制测试用 2×2 区域约束整个箭头、光晕和涟漪，区域外没有绘制。
- 三个独立测试进程使用透明 1×1 目标和遮挡窗口，运行实际 `AgentCursor`、`WindowSpaces` 和公共排序源码；捕获与输入入口替换为空实现。核实光标层级为 normal、位于遮挡窗口下且紧邻目标、裁切范围不超过目标、不接收鼠标且不成为键盘窗口，前台应用 PID 未变。首次面板 Space 登记尚未回传时按既有规则隐藏，测试随后在同一目标再次请求光标移动完成验证；本轮未修改 Space 失败的重试策略。
- 测试进程与自建窗口已清理，没有对用户窗口发送输入或启动捕获。`git diff --check` 通过。
- 真实应用切换及跨 Space 的视觉体验仍待安装后验收，不把模拟窗口测试称为真实业务验收。

安装后由用户手动把其他应用遮在目标窗口前，检查真实光标不会显示在遮挡应用上；点回目标后应恢复在原目标层级。再检查目标边缘的箭头与涟漪、目标移动/缩放、切换 Space，以及共享预览中的镜像。保持不抢焦点、不移动物理鼠标、不通过额外截图验证层级。
