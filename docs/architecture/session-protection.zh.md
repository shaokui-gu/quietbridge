# QuietBridge 会话保护生命周期

状态：2026-11-08 源码实现与回归范围说明，未在当前安装版生效。

## 生命周期与归属

同一宿主运行可以在操作应用、处理文件、思考和再次操作之间切换。
保护跨界面操作阶段保留；`quietbridge_task end` 不能代表整个宿主运行结束。
活动范围使用宿主真实 sessionId 与 requestId，阶段以 taskId 和连接的 ownerId 关联。
停止记录包含各阶段，不能只记最后一次 taskId。

| 事件 | 阶段与共享 | 会话保护 | 全局锁屏/防睡眠 |
| --- | --- | --- | --- |
| 阶段 end | 结束并释放本阶段预览 | 保留 | 保持 |
| 同轮次下一阶段 begin/bind | 重新核实目标；需匹配宿主归属 | 延续原登记 | 不重建解锁 episode |
| 120 秒无实际界面操作 | 中断阶段并释放预览 | 已核实宿主运行时继续有效 | 保持 |
| 本轮 FinalStop | 中断所属活动阶段 | 移除所属连接登记 | 其他参与者有效时保持 |
| SessionEnd | 撤销该会话各轮次 | 同上 | 同上 |
| 取消、断连、桥接退出 | 停止所属输入并回收资源 | 同上 | 同上 |
| 用户手动认证 | 等待真实解锁，再重新观察原目标 | 不结束任务 | 整机统一交还系统认证 |
| 退出 QuietBridge | 全局停止 | 全部撤销 | 全局清理 |

如果最后一个参与者退出时已有遮罩，先交还真实系统锁屏再移除遮罩。
手动解锁与自动解锁的区分只影响锁屏交接，不是任务取消信号。

## 有界活动与失效兜底

- 界面阶段租约为 120 秒；本连接实际界面操作续租。
- 宿主已回执关联的会话允许最长 1800 秒没有实际工具活动。
  相同宿主 session/request 的其他业务工具 PostToolUse 可以记录活动，不能创建保护。
- 无宿主归属证据时，仍按 120 秒连接活动兜底。
- 状态查询、ping、扩展心跳和保护 watchdog 均不能续宿主活动时间。
- 原生预览和保护分别设置 120 秒资源期限。桥接每 30 秒续自己的原生保护，
  前提是本会话仍有效；续保护不续预览，预览不能凭连接在线一直显示。
- 检查墙钟及单调时钟，防止睡眠或时钟回退无限延长保护。
- 宿主停止先写 tombstone，迟到工具回执不能恢复已结束运行。
  没有 requestId 时，新阶段可以标记新轮次，但必须保留上一代停止记录。

30 分钟是本次采用的无活动上限，不是整轮运行时长上限。
长时间没有工具输出的宿主任务仍可能到达此上限；未来只有宿主能证明执行状态的
生命周期接口才可替代此兜底，普通连接心跳不能冒充执行证明。

## 多会话聚合

原生 `TaskResourceLease` 按 socket clientId 持有保护登记。A/B 各自登记后：

1. A 释放、断开或超时，只移除 A。
2. B 仍有效时，保持全局控制器、防睡眠、当前遮罩与解锁 episode。
3. B 也退出后，全局释放一次。多个参与者同一次检查到期也只触发一次最后参与者清理。
4. 预览继续独占；第二连接申请预览返回占用，不能覆盖第一个预览。

若最后一个旧参与者已发起系统锁屏交接，此时新参与者到来，继续完成真实认证交接，
但保留新参与者的观察和保护登记，不让旧交接完成后清空新登记或再次自动解锁。

这些登记是独立连接的资源隔离，尚未构成完整多 Agent 并行能力。

## 当前支持边界

Python 仍使用唯一 activeTaskId 和进程内状态，原生仍使用 SpacePreview 单例、共享调度器。
两个连接可能分别持有保护，但当前不能同时拥有两个活动界面任务与两路预览。
Worker 故障隔离、浏览器多通道和逐调用可信身份仍依照
[多 Agent 运行时方案](multi-agent-runtime.zh.md) 实施。

Workbuddy 的 PostToolUse 是异步事后回执，可以证明某阶段归属并关联停止；
它不能证明共享 MCP 中下一次调用属于哪个会话。不能使用最后一条 hook、前台应用、
任务标题或模型填写的 sessionId 猜路由。

同一连接切换到新阶段时，若与保留保护的宿主归属不一致或尚未回执核实，
返回 SESSION_ROUTING_REQUIRED，在原生绑定前拒绝。原会话保护不被释放。
没有逐调用身份的共享连接不声明为会话隔离边界；已有阶段也不能承诺识别同连接的
其他 Agent。完整支持必须有宿主独立连接或可靠的调用上下文，再接入 Broker/Worker。

## 验证范围

Python 使用隔离临时目录、模拟 helper 与时钟验证：阶段结束后停止关联、
不同会话/轮次停止隔离、新阶段归属校验、30 分钟活动上限、120 秒兜底、
watchdog 不续活动、迟到回执防复活，以及无活动任务时后台 watcher 收尾。

Swift 使用资源租约模拟时钟验证：多参与者释放/断连/到期隔离、同时到期只清理一次、
保护续租不续预览，以及预览独占。锁屏交接状态机回归使用无桌面输入测试。
这些测试不替代真实多宿主并发、锁屏及自动解锁验收。
