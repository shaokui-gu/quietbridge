# QuietBridge 0.6.10（93）

浏览器扩展更新至 0.4.5，包含会话同步队列阻塞修复，沿用 0.6.9 的导航同步、轻量复核和覆盖安装流程。

## 本次修订

- 观察器加载、配置增加最多 3 秒等待；被动标签查询与旧任务清理增加最多 1.2 秒等待，避免 Chrome API 无回执时永久阻断会话同步。
- 配置观察器使用 injectImmediately，同一绑定／文档／epoch 的初始化最多尝试两次；失败后保留原目标，不重放页面输入。
- 页面清理与调试连接释放独立执行；多个旧目标并行清理。迟到配置和清理检查执行期限，旧观察器停止核对绑定身份。
- 新增 observerStatus 和 lifecycleError，区分真实连接状态与页面观察就绪状态。未就绪时返回 BROWSER_OBSERVER_NOT_READY，并给出有界只读检查及通知用户的恢复指引。
- 保留初始化、候选查询、清理的具体失败阶段，避免将本地生命周期错误误报为 host_unavailable。

## 验证范围

Chromium Node 88 项、MCP Python 311 项通过。测试覆盖真实 worker 入口的合成无回执、有限重试、迟到回执、三会话隔离及停止、调试释放与清理顺序。

现场日志确认根通道继续同步而会话通道停滞，未发现对应时段的新进程崩溃报告。本轮修复的是已在隔离测试中复现的队列阻塞路径；尚未完成安装后的实机稳定性复测。
