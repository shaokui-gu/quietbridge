# QuietBridge 0.6.9（92）

浏览器扩展更新至 0.4.4，包含导航后文档同步、轻量复核和命令回执处理修订，沿用 0.6.8 的覆盖安装退出与恢复流程。

## 本次修订

- navigate 受理后先发布等待新文档边界；同一绑定内核对原标签的真实 frame，补齐漏报导航、同文档 URL 变化和文档恢复。
- 导航后的观察最多等待 3 秒再入队；已入队命令仍固定原文档，不迁移到替换文档。
- 保留最近的过期／取消终态，不因下一条命令覆盖而立即变为 unknown。未知输入不重放。
- 已确认受理的导航可用当前新文档 screenshot/read/diagnostics 轻量复核；点击、填写等输入仍需 snapshot，旧 ref 不恢复有效。
- 已请求命令的无效回执记录为 INVALID_BROWSER_RESULT 并确认消费，避免阻断后续心跳；未请求的回执和非法握手仍拒绝。
- 区分本地请求拒绝、连接不可用和应用退出；页面文档脚本增加有界等待。
- 工具说明优先推荐分页 read 阅读长页面，截图仅证明当前视口；过期文档指引优先核对原任务与原标签。
