# QuietBridge 0.6.28（111）

打包日期：2026-11-13。扩展版本保持 0.4.14。

预览框改为普通窗口层，持续保持在宿主窗口紧邻上方，多会话卡片连续排列。用户将其他应用置前时，该应用同时覆盖宿主与预览，不再由全局浮动层将两者分隔。实际顺序未通过回读验证时隐藏内容、阴影与鼠标命中，确认后恢复显示；不激活宿主或切换用户 Space。
