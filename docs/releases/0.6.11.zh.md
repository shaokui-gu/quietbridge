# QuietBridge 0.6.11（94）

扩展更新至 **0.4.6**，包含 0.6.10 验收后修复。

- 后台 click 不再等待独立 mouseMoved 预备悬停，保留点击前目标、文档、epoch 与命中核验，以及 CDP 按下／松开；未知结果不重放、不回落前台输入。
- 导航落地地址变化时明确提示当前 snapshot 复核，继续原绑定，无需重新 assign。
- 阶段结束后可以幂等 unshare；end 返回 previewCleanup，区分共享释放、失败、未确认与原生连接已关闭。宿主会话保护继续按原设计跨阶段保留。
- snapshot 增加 coverage 范围和截断标记；原生旧快照精确返回 STALE_SNAPSHOT。
- Native host 默认只记录 stderr 和异常退出；正常启动／退出日志可用 QUIETBRIDGE_NATIVE_HOST_DEBUG=1 显式开启。

验证：Chromium Node 90 项、MCP Python 318 项、打包／部署脚本 47 项、安装器 6 项通过；隔离真实 headless Chrome 本地页面连续 20 次 trusted click 通过。真实后台窗口、不抢焦点和长时间稳定性仍需安装后复测。
