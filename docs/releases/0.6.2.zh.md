# QuietBridge 0.6.2（build 85）

## 共享预览

- 修正额外描边和外层方角：玻璃背景放到画面下方，最外层及视频统一使用 12pt 连续圆角裁切；移除自绘描边，由透明面板生成阴影。
- 单窗口共享忽略额外捕获框架和原窗口阴影，保持透明边角；不改变应用或桌面共享范围。
- 拖动画面可临时避让，松开后保留 30 秒，再吸附回宿主右上角；重复拖动重新计时。拖动本身不激活宿主或源应用。
- 宿主移动、缩放或身份改变会立即取消临时位置，下一次 30Hz 跟随回调恢复吸附；隐藏、结束共享或换目标时清除拖动状态。
- 左下角仍是唯一等比缩放入口。临时缩放保持当前右上顶点和原倒计时；临时位置限制在宿主所在显示器可见范围。

Figma 和交互细节见 [共享预览设计](../design/preview-window.zh.md)。
