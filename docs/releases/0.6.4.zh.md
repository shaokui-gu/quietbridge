# QuietBridge 0.6.4（build 87）

## 阶段与会话保护

- `quietbridge_task end` 结束当前界面阶段并释放预览，保留会话保护。
- 保留各阶段的宿主关联；阶段结束后 FinalStop/SessionEnd 仍可撤销本连接。
- 界面阶段 120 秒空闲后关闭预览。已核实宿主归属的会话保护允许 30 分钟无实际工具活动；未核实归属时为 120 秒兜底。
- 同一运行中的其他业务工具可通过 PostToolUse 记录活动时间；不保存内容。状态查询、ping、扩展心跳及 watchdog 不续宿主活动。
- 原生保护按连接聚合。A 释放、断开或到期不撤销仍有效的 B；最后一个参与者退出才全局收尾。
- 同时到期只进行一次最后参与者清理；保护续租不续预览。旧锁屏交接完成后不清空中途加入的新保护。
- 新阶段需核实与保留保护属于同一宿主运行，身份缺失或冲突返回 SESSION_ROUTING_REQUIRED，在原生绑定前拒绝。
- 迟到回执不能复活已停止运行；SessionEnd 保留会话级停止记录。

完整说明：[会话保护生命周期](../architecture/session-protection.zh.md)。

## 支持边界与签名

当前仍是单活动界面任务、单共享预览。保护参与登记隔离不等于完整多 Agent 并行；共享 MCP 的可靠逐调用路由及多 Worker/预览仍待实现。

应用、helper 与授权插件使用 sign/ 中的 Developer ID Application 证书及匹配描述文件签名，沿用 0.6.x 身份。当前没有 Developer ID Installer 证书，PKG 外层未签名、未公证。
