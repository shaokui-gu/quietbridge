# QuietBridge 0.6.14（97）

本版补齐跨 Space 画面不更新的诊断证据，扩展保持 0.4.6。此前重开预览仍为纯色的实验不足以排除捕获参与问题：关闭期间没有源画面对照，旧版 released 也未证明 stopCapture 已完成。因此本版不宣称修复 Chrome 离屏呈现。

- 按原生进程、窗口和不可变流代际记录捕获准备、启动请求/成功/失败、停止请求/成功/失败和 delegate 停止事件。面板立即关闭，异步停止回执独立记录；旧流完成不会被归到新流。
- 如果关闭发生在 startCapture 尚未返回时，记录停止请求并等待该次启动成功或失败后调用 stopCapture，避免停止先完成、旧流随后启动。不会等待系统 API 才关闭面板。
- `previewCleanup.captureStop`、`preview.captureLifecycle` 和 `preview.captureStop` 保留脱敏后的生命周期。released 仅说明面板/租约释放；stopState=completed 且 stopConfirmed=true，或对应 captureStopCompleted 日志，才说明停止 API 成功返回。失败/缺失不证明泄漏，成功返回也不代表能够验证系统内部资源全部回收。
- 在既有输入缓冲区上每秒最多一次稀疏采样，分别统计整窗与中央区域变化。BGRA 检查 alpha 范围；NV12 中央区域同时检查亮度和色度。记录格式、尺寸、stride、固定颜色元数据、中央近似纯色程度和样本年龄。
- 中央区域是排除典型顶部工具栏的固定裁剪，不是 DOM 正文边界；稀疏样本不证明全部像素一致。enqueue 不证明成功显示，DOM complete 也不证明源窗口已呈现。未知格式计数并清空旧格式信息，不将旧元数据描述成新帧。
- 仅记录计数、范围和固定格式标识，不保存图像、像素指纹、页面标题、URL、用户输入或平台错误原文。不新增截图，不激活目标、不切 Space、不移动物理鼠标，继续保留正常 FinalStop 清理。
