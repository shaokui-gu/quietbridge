# QuietBridge 0.6.16（99）

离屏呈现诊断版，配套 QuietBridge Browser 0.4.7。尚未修复其他 Space 的灰色画面，也不增加自动截图或激活窗口策略。

- 新增固定阶段 `render_probe`：inspect / attach / enable / layout / capture。阶段互不自动串联，不经过输入命令的弹窗保护前置链路。检查不连接、连接不启用、启用不查布局、布局不截图；截图只使用当前绑定和文档30秒内的视口缓存，派发前消耗缓存，单次执行、丢弃图像、不自动重试。没有任意 CDP 入口。
- 返回固定阶段时间、连接和Page启用前后状态及数值尺寸；既有连接如实标记，不能当作首次连接。探针不是普通被动观察，不清除原动作复核要求，旧扩展在能力核验时明确拒绝。
- bridge 日志保存经校验的阶段元数据，分析工具按 taskId/commandId 去重；不记录图像、页面内容、URL 或任意错误文本。结合原生源帧统计，在同一流内区分布局查询和截图附近的变化。
- 修复原生 RequestCoordinator 回执字段投影遗漏，带出 frameProgress / captureLifecycle / captureStop；非法/缺失元数据不伪造停止确认。requested 和 stopConfirmed 仍按各自流代际解释。
- 纠正此前复盘的路径描述：navigate 的 execute 使用 tabs.update，但 run 前置保护也会 attach/enable。因此不能把上轮 screenshot 认定为首次连接调试器，截图附近恢复仍只是时间关联。

验证：扩展97项、MCP全量353项、打包47项、诊断分析9项及相关Swift10项通过；Release构建通过。MCP全量中曾有一次既有长期租约用例断言失败，单独复测和后续全量复查通过，未改租约逻辑。全部浏览器测试使用模拟API；本轮没有执行真实浏览器操作、共享、截图或重启安装。
