# QuietBridge 0.6.8（91）

浏览器扩展版本保持 0.4.3。本次改动完善覆盖安装的应用退出时机，不改变网页输入通道。

## 安装行为

1. 环境、配置及现有应用签名预检通过后，保存安装前的运行状态、独立旧版应用及恢复脚本。
2. 停止当前用户的已验证菜单栏进程，确认退出后才允许安装器替换文件。首次向导／尚未监听状态端口的进程也在核验范围内。
3. 安装后核对暂停记录的版本和构建号；原来运行时启动并核验新版，原来关闭时保持关闭。可选“安装完成后立即运行”仍由原生安装器选项控制。
4. 部署或新版启动失败时，先回滚用户文件，再恢复保存的旧版运行状态。配置冲突保留用户改动，并报告恢复未完成。

退出超过五秒仍未完成会阻止替换文件；不强杀菜单栏进程，不退出 Workbuddy、Chrome 或目标应用。

## 中断恢复

macOS 在复制 PKG 文件阶段失败或取消时，可能不执行 postinstall。此时保留暂停记录和旧版备份，不通过定时猜测自动重启应用。

安装前会生成独立恢复入口：

    <现有用户运行目录>/upgrade-recovery/<本次安装ID>/恢复安装.command

准备日志和下次预检会输出准确路径；即使系统目录中的新版脚本尚未复制，该入口也能使用。新版系统支持文件已落地后，原有“恢复安装.command”同样支持暂停记录。未恢复的安装会阻止再次覆盖。

恢复范围为用户文件和菜单栏运行状态，不能还原 PackageKit 已替换的系统文件。部署已持久提交、仅末尾状态记录中断时，恢复会完成记录，不回退已正常运行的新版。
