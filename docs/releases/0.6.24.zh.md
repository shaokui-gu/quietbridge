# QuietBridge 0.6.24（107）

扩展版本保持 0.4.12。

窗口被其他会话占用时，TARGET_IN_USE 现在返回可核实的窗口、任务和 WorkBuddy 会话身份。控制面板入口改为“任务与窗口”，可选中实际占用者，点击“停止此会话控制”，撤销该宿主本轮的界面控制并释放资源。扩展离线、未完成标签分配或原生请求持有任务文件锁时也可发起停止。
