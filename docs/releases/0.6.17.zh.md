# QuietBridge 0.6.17（100）

配套 QuietBridge Browser 0.4.9。本版把后台网页预览切换为扩展主动获取的网页内容定时帧，面板标注“非整窗视频”，用于绕开已确认的 Chrome 离屏系统窗口源帧故障。

- 默认网页共享及 `source=window` 采用固定任务标签的网页视口，不包含浏览器工具栏和原生对话框；显式应用/桌面共享及原生任务保留系统捕获路径。
- 网页帧绑定任务、窗口、标签、文档及导航版本。导航未就绪时清旧画面，过期帧丢弃，停止、撤销或换绑即清理释放；页面命令优先，不重放输入，不激活目标或切换 Space。
- 获取最高每秒一次，每轮只取一次 JPEG，大小和调用等待有界；不延长任务实际活动租约。最新一帧经现有 JSON 邮箱短暂落盘，消费后移除，不宣称纯内存传输。
- 包含此前尚未安装的弹窗守卫旧 owner 清理修复。旧页面驻留闭包的升级边界仍见对应实现记录。

自动化验证：Node 108 项、MCP 362 项、打包部署 47 项、Swift 285 项通过。Swift 跳过系统剪贴板在沙箱不可用的 clipboardPaste 测试，未宣称完整套件通过。

实现细节及验收边界见 [网页内容预览源修复](../implementation/2026-11-11-browser-content-preview-fix.zh.md)。本次打包不安装、不重载扩展、不启动页面捕获；真实离屏画面验收仍待新包安装后进行。不继续旧 A/B/C 重复取证。

安装后应确认 Chrome 扩展实际重载到 0.4.9 并上报 `browser_preview` 能力，仅磁盘 manifest 更新不足以证明运行版本已升级。
