# QuietBridge 0.6.5（88）测试包

本版实现同一个 Workbuddy 最多三个会话分别操作独立目标，并持续共享三个窗口。

- 可信会话路由：宿主 hook 为每次调用生成与工具及参数绑定的一次性凭据，不从前台、模型输入或最后一个 hook 猜测归属。
- 独立 Python 与原生执行进程、句柄、任务文件和浏览器通道；停止或崩溃只回收所属一路。
- 预览以卡片堆叠，点击露出的标签切换；切卡不改变任务绑定、不重建共享流。前卡 15fps、后卡 5fps。
- 控制面板增加会话选择，活动、下载和截图按所选任务操作。会话结束后清空选择。
- 第四路及相同目标冲突明确拒绝；同一普通应用不同窗口按进程保守互斥。

浏览器扩展随包更新至 0.4.1。安装后请在 Chrome 扩展管理页重新加载 QuietBridge Browser，确认新版本生效。
已有稳定连接器可在调用之间载入新版；首次工具调用可能返回 CONNECTOR_UPDATED，需先核实权限和目标，再建立新阶段。

已通过自动化组件测试、三原生客户端崩溃隔离及自建窗口卡片切换实测；实测前台 PID 和物理鼠标位置未变化。
尚待安装后进行真实 Workbuddy 三会话连续 30 分钟综合验收。DSH 插件仍未交付。
