# QuietBridge 0.6.0（build 83）

## 安装

安装包：`dist/quietbridge-0.6.0.pkg`。可覆盖现有 Workbuddy CUA 安装，完成后从
应用程序打开 QuietBridge，或在安装器中勾选“安装完成后立即运行”。

新版签名身份：

| 组件 | Bundle ID |
| --- | --- |
| App | `com.quietbridge.app` |
| Helper | `com.quietbridge.helper` |
| Authorization Plug-in | `com.quietbridge.AuthorizationPlugin` |

使用 `sign/` 中提供的 Developer ID 证书和三个匹配的 QuietBridge 描述文件；
临时钥匙串仅用于构建，完成后恢复搜索列表并删除。应用与组件严格签名核验通过。
PKG 外层未签名、未公证；当前签名材料中没有 Developer ID Installer 证书。

Bundle ID 改变后需在首次启动向导重新核实并授予辅助功能和屏幕录制。
旧锁屏授权插件需要在应用的插件管理入口选择安装/更新，之后注销并重新登录。
迁移保留原始授权规则备份，主 PKG 不自动启用或改写授权规则。
