# QuietBridge 0.6.12（95）诊断版

用于定位 Chrome 在其他 macOS Space 中正文与共享预览不更新的问题，不是刷新修复版。浏览器扩展保持 0.4.6。

- 每条预览流增加捕获帧状态、稀疏像素变化、显示层提交与背压丢帧统计，最多每 5 秒记录一次；不保存像素、指纹或页面正文。
- 区分捕获回调与显示层提交。提交不代表已呈现，静态页面不据此判为冻结；现有捕获与绘制策略保持原样，以保留对照现场。
- 新增本地固定测试页、阶段时间标记与脱敏统计分析工具 `tools/preview_diagnostics.py`，不控制浏览器或桌面。
- 工具能力说明按操作对象区分 Chrome 扩展网页操作与原生窗口操作：task begin 可指定 targetSurface；回执提供 routing；冲突路由明确拒绝，网页失败不自动改走原生输入。既有调用保持兼容。

验证：MCP 全量 331 项、Swift 预览与操作日志相关 34 项、本地诊断工具 5 项通过；Swift release 构建通过。真实跨 Space 的对照实验仍需安装后由用户手动切换桌面复现。

产物：`dist/quietbridge-0.6.12.pkg`。使用用户提供的 sign/ 证书与匹配 profiles 签署 App、Helper 和授权组件；PKG 容器沿用未签名、未公证方式。打包不等于安装。
