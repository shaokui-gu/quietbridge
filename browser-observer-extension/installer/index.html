workbuddy-cua 浏览器扩展安装

本页只在本机 127.0.0.1 上运行。宿主部署与状态检测全自动；扩展装载与授权各需你点一下。

为什么不能全自动：Chrome 从 137 起移除了 --load-extension，扩展无法被程序装进日常配置； 而 chrome.permissions.request 按 Chrome 规定必须由扩展页面内的用户手势触发，网页无法代为调用。 你的 Chrome 是 读取中…。

1部署原生消息宿主已完成

写入 ~/Library/Application Support/WorkbuddyExtension/，并在 Chrome 的 NativeMessagingHosts 登记 com.cua.browser_observer，只允许当前扩展 ID 调用。

2在 Chrome 中加载扩展已安装

—
  1. 地址栏输入 chrome://extensions（网页禁止跳转到 chrome://）。
  2. 打开右上角 开发者模式，点 加载已解压的扩展程序。
  3. 文件框里按 ⇧⌘G，粘贴上面路径并回车，选中该文件夹。
装好后本页会在 2 秒内自动识别，无需手动刷新。

3授予站点权限已授权

回到 chrome://extensions，在扩展卡片上点 重新加载。重载会触发扩展打开授权页， 你在那一页点 启用，再在 Chrome 弹框里点 允许 即可。

复制后按 ⌘L 选中地址栏，⌘V 粘贴，⏎ 打开。 网页与外部程序都无法直接跳转 chrome-extension://——Chrome 会以权限违例拒绝，这是浏览器安全设计。

状态来自本机读取 Chrome 配置目录（只读，不写入），属于尽力而为的检测；最终仍以 chrome://extensions 显示为准。 本页不收集数据，写操作只有「部署宿主」一项，且需要启动时生成的一次性令牌。
