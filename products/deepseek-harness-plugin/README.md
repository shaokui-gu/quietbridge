# QuietBridge for DeepSeek Harness

Planned market product. It will contain the host adapter, verified plugin
manifest and host-specific guidance. It will reuse the same signed QuietBridge
application and browser extension as the Workbuddy connector.

This directory does not contain an installable plugin yet. The host contract and
multi-agent broker must be implemented and verified before publication. See
`adapters/deepseek_harness` and the architecture document for prerequisites.
